# Real-Time Weather Skill for Gemma 4

Free, open-source weather skill using Open-Meteo API (no API key needed).

## Features
- **Current Weather**: Temperature, humidity, wind, conditions
- **Hourly Forecast**: Next 24-48 hours with precipitation probability
- **Daily Forecast**: Up to 16 days ahead with UV index, sunrise/sunset
- **Location Search**: Find any city worldwide
- **Auto Units**: Celsius/Fahrenheit based on preference

## Data Source
- [Open-Meteo](https://open-meteo.com) - Free weather API
- No registration required
- No rate limits for personal use

## Installation

1. Host these files on GitHub/GitLab or any web server
2. In Google AI Edge Gallery app: **Agent Skills** → **Load from URL**
3. Enter: `https://your-domain.com/gemma-weather-skill/manifest.json`

## Usage Examples
- "What's the weather in Tokyo?"
- "Will it rain in London tomorrow?"
- "Hourly forecast for New York"
- "7-day forecast for Paris"
